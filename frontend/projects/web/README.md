# AgentBond Web Application

> Decentralized UI for AI Agent Pre-Action Verification & Intelligence Suite with Algorand TestNet Wallet Authentication & x402 Micropayments.

## Overview

**AgentBond Web App** is a modern React/Vite web application providing an enterprise interface for autonomous AI agent verification:
- **AI Guardian Suite**: 12 pre-action verification engines with dynamic thematic backdrops and interactive test benches.
- **Custom Agent Request Portal**: Submit specialized agent specifications with automated Excel/CSV backend persistence.
- **Sign-In with Algorand (SIWA)**: Nonce-based cryptographic session authentication.
- **On-Chain Audit Explorer**: Interactive transaction inspector showing exact endpoints, cryptographic proofs, and settlement hashes.

---

## 🛠️ Quick Start

```bash
# 1. Install dependencies
npm install

# 2. Start Vite development server
npm run dev
```

App runs at `http://localhost:5173`.
